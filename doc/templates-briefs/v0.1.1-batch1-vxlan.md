## 1. huawei_vrp_vxlan_evpn_l2vpn

**配置示例**（目标输出）：
```
evpn-overlay enable
bgp 65000
  peer 10.1.1.1 as-number 65001
  peer 10.1.1.1 connect-interface LoopBack0
  #
  l2vpn-family evpn
    peer 10.1.1.1 enable
    peer 10.1.1.1 advertise l2vpn evpn
bridge-domain 10
  vxlan vni 10010
interface Vbdif10
  ip address 10.1.10.1 24
```

**参数**：

| 参数名 | 类型 | 必填 | 说明 | 示例值 |
|---|---|---|---|---|
| local_asn | int | 是 | 本端 AS 号 | 65000 |
| rd_ip | string | 是 | BGP peer 互联 IP（本端 Loopback） | 10.0.0.1 |
| vtep_peers | array | 是 | 远端 VTEP IP 列表 | [{address: "10.1.1.1", remote_asn: 65001}] |
| bridge_domain_id | int | 是 | BD ID | 10 |
| vni | int | 是 | VXLAN VNI | 10010 |
| vbdif_ip | string | 是 | VBD 接口 IP/掩码（任意网关） | 10.1.10.1/24 |
| advertise_arp | bool | 否 | 是否抑制 ARP 泛洪 | true |

**版本**：VRP 8.180 - 8.999（CE12800/CE6880/NE40E 系列）
**来源**：华为 VRP 8.180 配置指南 - VXLAN/EVPN 章节

## 2. huawei_vrp_vxlan_anycast_gateway

**配置示例**（目标输出）：
```
evpn-overlay enable
bridge-domain 20
  vxlan vni 10020
interface Vbdif20
  ip address 10.1.20.1 24
  arp collect host
  vxlan anycast-gateway enable
  #
  evpn anycast-gateway local-mac 00-00-5e-00-01-20
```

**参数**：

| 参数名 | 类型 | 必填 | 说明 | 示例值 |
|---|---|---|---|---|
| bridge_domain_id | int | 是 | BD ID | 20 |
| vni | int | 是 | VXLAN VNI | 10020 |
| vbdif_ip | string | 是 | 任意网关 IP/掩码 | 10.1.20.1/24 |
| anycast_gw_mac | string | 是 | 统一网关 MAC（所有 Leaf 必须一致） | 00:00:5e:00:01:20 |
| vrf | string | 否 | VRF 名（VPN 实例） | default |

**版本**：VRP 8.180 - 8.999
**注意**：anycast-gateway 需提前全局使能 `evpn-overlay enable`，所有 Leaf 的 MAC 必须对齐。

## 3. cisco_iosxe_vxlan_evpn_l2vpn

**配置示例**（目标输出）：
```
nv overlay evpn
feature vn-segment-vlan-based
feature nv overlay
!
l2vpn evpn
  replication-type static
  router-id Loopback0
!
vlan 10
  vn-segment 10010
!
interface nve1
  no shutdown
  source-interface Loopback0
  host-reachability protocol bgp
  member vni 10010
    ingress-replication protocol bgp
!
router bgp 65000
  address-family l2vpn evpn
    neighbor 10.1.1.1 activate
    neighbor 10.1.1.1 send-community both
  !
  l2vpn evpn instance 10 point-to-point
    rd 10.0.0.1:10
    route-target import 65000:10010
    route-target export 65000:10010
```

**参数**：

| 参数名 | 类型 | 必填 | 说明 | 示例值 |
|---|---|---|---|---|
| local_asn | int | 是 | 本端 BGP AS | 65000 |
| router_id | string | 是 | VTEP Router ID（Loopback IP） | 10.0.0.1 |
| vtep_peers | array | 是 | 远端 VTEP peer 列表 | [{address: "10.1.1.1", remote_asn: 65001}] |
| vlan_id | int | 是 | 接入 VLAN ID | 10 |
| vni | int | 是 | VXLAN VNI | 10010 |
| evpn_instance_id | int | 是 | EVPN instance ID（一般与 vni 同号） | 10 |
| rd | string | 是 | Route Distinguisher | 10.0.0.1:10 |
| route_target | string | 是 | RT（import/export 同值） | 65000:10010 |

**版本**：IOS-XE 17.06 - 17.999（Catalyst 9000/Nexus 9500-FX/N9K-C9500）

## 4. cisco_iosxe_vxlan_anycast_gateway

**配置示例**（目标输出）：
```
fabric forwarding anycast-gateway-mac 0000.5e00.0120
!
vlan 20
  vn-segment 10020
!
interface nve1
  member vni 10020
    ingress-replication protocol bgp
!
interface Vlan20
  ip address 10.1.20.1 255.255.255.0
  fabric forwarding mode anycast-gateway
!
router bgp 65000
  l2vpn evpn instance 20 point-to-point
    rd 10.0.0.1:20
    route-target import 65000:10020
    route-target export 65000:10020
```

**参数**：

| 参数名 | 类型 | 必填 | 说明 | 示例值 |
|---|---|---|---|---|
| anycast_gw_mac | string | 是 | 统一任意网关 MAC | 0000.5e00.0120 |
| vlan_id | int | 是 | SVI/VLAN ID | 20 |
| vni | int | 是 | VXLAN VNI | 10020 |
| vlanif_ip | string | 是 | SVI IP/掩码 | 10.1.20.1/24 |
| evpn_instance_id | int | 是 | EVPN instance ID | 20 |
| rd | string | 是 | RD | 10.0.0.1:20 |
| route_target | string | 是 | RT | 65000:10020 |

**版本**：IOS-XE 17.06+（Nexus 9300-EX/FX/FX2 全部支持）
**注意**：所有 Leaf 必须配同一个 `fabric forwarding anycast-gateway-mac`，否则 ARP 振荡。

## 5. h3c_comware_vxlan_evpn_l2vpn

**配置示例**（目标输出）：
```
vsi vsi10
  gateway vsi-interface 1
  #
  evpn encapsulation vxlan
  vxlan vni 10010
  vxlan local-arp enable
!
interface Vsi-interface1
  ip address 10.1.10.1 24
!
bgp 65000
  peer 10.1.1.1 as-number 65001
  peer 10.1.1.1 connect-interface LoopBack0
  address-family l2vpn evpn
    peer 10.1.1.1 enable
```

**参数**：

| 参数名 | 类型 | 必填 | 说明 | 示例值 |
|---|---|---|---|---|
| local_asn | int | 是 | 本端 AS | 65000 |
| vtep_peers | array | 是 | 远端 VTEP peer 列表 | [{address: "10.1.1.1", remote_asn: 65001}] |

| vni | int | 是 | VXLAN VNI | 10010 |
| vsi_interface_id | int | 是 | VSI 接口编号（关联网关） | 1 |

**版本**：Comware 7.1.070 - 7.999（CE/S12500R/S6850/S9850）

## 7. juniper_junos_vxlan_evpn_l2vpn

**配置示例**（目标输出）：
```
set routing-instances vsrx-evpn instance-type evpn
set routing-instances vsrx-evpn vlan-id 10
set routing-instances vsrx-evpn l3vpn no
set routing-instances vsrx-evpn vxlan vni 10010
set routing-instances vsrx-evpn protocols evpn encapsulation vxlan
set routing-instances vsrx-evpn protocols evpn control-plane bgp
set routing-instances vsrx-evpn route-distinguisher 10.0.0.1:10
set routing-instances vsrx-evpn vrf-target target:65000:10010
!
set protocols bgp group RR family evpn signaling
set protocols bgp group RR neighbor 10.1.1.1
set protocols bgp group RR local-address 10.0.0.1
```

**参数**：

| 参数名 | 类型 | 必填 | 说明 | 示例值 |
|---|---|---|---|---|
| instance_name | string | 是 | routing-instance 名 | vsrx-evpn |
| vlan_id | int | 是 | VLAN ID | 10 |
| vni | int | 是 | VXLAN VNI | 10010 |
| rd | string | 是 | RD | 10.0.0.1:10 |
| vrf_target | string | 是 | RT | 65000:10010 |
| bgp_neighbor | string | 是 | 远端 VTEP/Route-Reflector IP | 10.1.1.1 |
| local_address | string | 是 | 本端 Loopback IP | 10.0.0.1 |

**版本**：Junos 21.2R1 - 22.999（QFX5120/QFX10002/PTX10003/MX204）
**注意**：Junos 用 set 风格配置，meta.yaml 里 output_format 标 `cli` 但实际是 set 列表。

## 8. juniper_junos_vxlan_anycast_gateway

**配置示例**（目标输出）：
```
set routing-instances anycast-gw instance-type virtual-switch
set routing-instances anycast-gw vlan-id 20
set routing-instances anycast-gw vxlan vni 10020
set routing-instances anycast-gw routing-interface irb.20
set routing-instances anycast-gw protocols evpn encapsulation vxlan
set routing-instances anycast-gw protocols evpn default-gateway do-esi-switching
!
set interfaces irb unit 20 family inet address 10.1.20.1/24
set interfaces irb unit 20 mac 00:00:5e:00:01:20
```

**参数**：

| 参数名 | 类型 | 必填 | 说明 | 示例值 |
|---|---|---|---|---|
| instance_name | string | 是 | routing-instance 名（virtual-switch） | anycast-gw |
| vlan_id | int | 是 | VLAN ID | 20 |
| vni | int | 是 | VXLAN VNI | 10020 |
| irb_unit | int | 是 | IRB 接口 unit 号 | 20 |
| irb_ip | string | 是 | IRB 接口 IP/掩码 | 10.1.20.1/24 |
| anycast_gw_mac | string | 是 | IRB MAC（统一） | 00:00:5e:00:01:20 |

**版本**：Junos 21.2R1+
**注意**：Junos 用 IRB（Integrated Routing and Bridging）做任意网关，所有 Leaf 的 IRB MAC 必须一致。

## 9. arista_eos_vxlan_evpn_l2vpn

**配置示例**（目标输出）：
```
ip routing
ip vrf definition default
!
interface Loopback0
  ip address 10.0.0.1/32
!
interface Ethernet1
  no switchport
  ip address 10.255.0.1/31
!
router bgp 65000
  router-id 10.0.0.1
  neighbor 10.1.1.1 remote-as 65001
  neighbor 10.1.1.1 update-source Loopback0
  !
  address-family evpn
    neighbor 10.1.1.1 activate
    neighbor 10.1.1.1 route-reflector-client
!
vlan 10
  vn-segment 10010
!
interface Vxlan1
  no shutdown
  source-interface Loopback0
  vxlan-unicast-group 10.1.1.1
  vxlan vlan 10 vni 10010
```

**参数**：

| 参数名 | 类型 | 必填 | 说明 | 示例值 |
|---|---|---|---|---|
| local_asn | int | 是 | 本端 AS | 65000 |
| router_id | string | 是 | BGP Router ID（Loopback IP） | 10.0.0.1 |
| vtep_peers | array | 是 | 远端 VTEP 列表 | [{address: "10.1.1.1", remote_asn: 65001}] |
| vlan_id | int | 是 | VLAN ID | 10 |
| vni | int | 是 | VXLAN VNI | 10010 |
| vxlan_interface | string | 是 | Vxlan 接口名 | Vxlan1 |
| rd_auto | bool | 否 | RD 自动生成 | true |

**版本**：EOS 4.24+（DCS-7280/DCS-7500/DCS-7050 系列）

## 10. arista_eos_vxlan_anycast_gateway

**配置示例**（目标输出）：
```
ip virtual-router mac-address 00:00:5e:00:01:20
!
vlan 20
  vn-segment 10020
!
interface Vxlan1
  vxlan vlan 20 vni 10020
!
interface Vlan20
  ip address 10.1.20.1/24
  ip virtual-router address 10.1.20.1
!
router bgp 65000
  address-family evpn
    neighbor 10.1.1.1 activate
```

**参数**：

| 参数名 | 类型 | 必填 | 说明 | 示例值 |
|---|---|---|---|---|
| anycast_gw_mac | string | 是 | 设备级统一 VR MAC | 00:00:5e:00:01:20 |
| vlan_id | int | 是 | SVI VLAN ID | 20 |
| vni | int | 是 | VXLAN VNI | 10020 |
| vlanif_ip | string | 是 | SVI IP/掩码 | 10.1.20.1/24 |
| local_asn | int | 是 | 本端 BGP AS | 65000 |

**版本**：EOS 4.24+
**注意**：EOS 用全局 `ip virtual-router mac-address` 一行对齐所有 Leaf 的网关 MAC，比 Cisco/Huawei 简单。
